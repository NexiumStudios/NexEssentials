# NexEssentials

**All-in-One Minecraft Server Management**

NexEssentials is a modular Minecraft server management plugin for Paper and Purpur.

## Project Goals

- One plugin, multiple modules.
- In-game management GUI.
- Web-based dashboard.
- Modular and configurable features.
- Multiple database support.

## Platform

- Minecraft Java Edition
- Paper / Purpur
- Java 21
